## 🚀 Tecnologías Principales

- **Framework**: Next.js 15 (App Router)
- **UI & Estilos**: React 18, TailwindCSS, Radix UI Primitives
- **Autenticación**: NextAuth.js (Google OAuth & Credentials)
- **Formularios & Validación**: React Hook Form + Zod
- **Animaciones**: Framer Motion
- **Lenguaje**: TypeScript

## 📁 Estructura del Proyecto

- `app/(marketing)`: Landing page, precios, páginas legales.
- `app/(dashboard)`: Panel privado del usuario, subida de informes y resultados.
- `app/components`: Componentes modulares de UI (Tailwind + Radix).
- `lib/api`: Integración segura y tipada con el backend en Python.
